## Delivered behavior and completion fixes

- New and existing articles can save a draft or publish submitted fields in one transaction. Saving a published revision preserves the live snapshot; the editor distinguishes unsaved edits from saved unpublished changes. Normal News saves have no confirmation dialog or autosave.
- Internal links, sidebar links and return-to-list actions offer Keep editing, Discard changes and Save as draft. Failed saves retain the editor and intended destination. Confirmed sidebar navigation also closes the mobile menu. Cancelable same-document browser-history traversals use the Navigation API, without adding history entries. Browsers without that capability retain internal-link and native document-unload protection; custom dialogs/async saving during tab close are not promised.
- Never-published Draft, Published, explicitly Unpublished and retained Deleted states remain distinct. Super Admins/Editors can delete with the exact stored-title phrase. Deletion reserves the URL, retains administrative history, revokes public eligibility and rejects stale editing. Confirmed publication/deletion retries retain their mutation key.
- Date, Time and Time zone are separate. The new-editor instant is captured once, defaults to Africa/Lagos and displays WAT (UTC+01:00). UTC storage, historical instants and date-only membership fields are preserved. Future instants may be saved as drafts but cannot publish. Editorial dates use the saved zone, with Lagos fallback for older snapshots. Shared dashboard timestamps and Activity Log filter boundaries use WAT; elapsed expiry/retry rules remain unchanged.
- `/news` and `/news/[slug]` render public snapshots on the server, with pagination, empty state, safe rich text, optional validated retained covers, date-only metadata and back navigation. Draft/unpublished/deleted records return a complete SSR 404 using the existing global-boundary workaround. The News proxy performs a validated snapshot eligibility read before article rendering; database failure is not treated as deletion. Homepage links use real article URLs; the feed remains Featured first, then newest instant, deterministic slug ties and at most four unique articles. Canonicals use configured `ADMIN_ORIGIN`; prelaunch noindex remains.
- One private shared toaster supports success/error/info/warning, concise messages, deduplication, navigation persistence and dismiss controls. Each toast has its own reading timer, paused during hover/focus; icons use MingCute/currentColor. Field validation and critical form errors remain inline. Cache-refresh uncertainty is distinct from a committed mutation.

The completion corrects two blockers in the merged implementation: News lifecycle/idempotency columns had been placed on the Research ORM model, causing duplicate-column/type errors and missing News fields; and server record metadata was entering editable state, causing strict subsequent saves and snapshot comparisons to fail. ORM definitions now match existing migrations, and editor state contains only editable fields. Historical research status/storage behavior is restored. No new migration or dependency is introduced.

## Six owner walkthroughs

1. **Authoring:** as Editor, add an image-free article, save a draft, reopen it and publish. Also publish a new article directly. Neither action should require an extra save confirmation. Verify concise success feedback and retained fields on a failed save.
2. **Exiting:** edit, then select All news or a sidebar destination. Exercise Keep editing, Discard and Save as draft. Repeat edit → undo edits → edit → browser Back; check that the chosen action reaches the intended destination. Cancel a native reload warning. Pristine forms should leave quietly.
3. **Snapshots and reading:** publish an article, open its homepage card, listing and detail page on phone/desktop. Save a revised title/body as a draft: the old public version stays live and the editor shows Unpublished changes. Publish changes to replace it. Check formatting, date, back link and pagination when enough isolated records exist.
4. **States and deletion:** unpublish and verify a public 404 plus an Unpublished directory label; republish. At the bottom of Edit, try an incorrect deletion phrase, Cancel/Escape, then the exact phrase. The article disappears publicly; its URL/history remain reserved. A stale editor cannot restore it. Lead/anonymous callers must have no News administration access.
5. **Dates:** confirm the new-editor WAT date/time does not reset while typing. Exercise a date around Lagos midnight and a supported alternate zone. Public pages show the editorial date only. Future publication fails clearly while a future draft saves. Activity Log timestamps and day filters should agree in WAT; member join dates do not shift.
6. **Notifications:** save account settings and perform permitted membership, administrator, Research and News changes. Check one meaningful toast per mutation, inline validation, dismiss/keyboard access, navigation persistence and readable mobile positioning. A cache-refresh warning must acknowledge the committed change without claiming a confirmed refresh.
