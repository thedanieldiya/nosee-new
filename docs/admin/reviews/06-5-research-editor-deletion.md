## Delivered behavior

Automatic hidden server-owned slugs, stable on rename, with transactionally allocated `-2`, `-3` suffixes and retained deleted-slug reservations. Latin diacritics/punctuation normalize; empty ASCII results use `research-group`; candidate length stays at most 80. No other current editable slug field exists. Future publishing editors follow this convention; existing public routes are unchanged.

Focus-area removal is a labelled MingCute delete icon immediately beside each input: 44px square/input height, transparent borderless default, restrained destructive hover, visible keyboard focus and focus transfer to a remaining input or Add. Existing covers are preserved; no selector, editable alt or fake upload. Working alt is derived server-side from the current name; published snapshots keep their original content/alt until republished. Image-free publication is permitted.

Free **Tiptap 3.32.0** selected extensions provide paragraph/H2/H3, bold/italic, both lists, links and undo/redo. Shared counting uses visible Unicode graphemes and block/line separators, not serialized markup. The visible counter is not a live region. Strict server validation limits formatting/attributes, safe HTTP(S)/mailto links, 6,000 graphemes, 1,200 nodes, depth 10 and 96,000 serialized characters. HTTP bodies are bounded at 128 KiB for structured Unicode text. Preview/public snapshots use one escaped React renderer contract; no unsafe HTML. Legacy strings and blank lines remain supported, without rewriting historical snapshots. Dependencies stay inside research edit/create client bundles.

Super Admin typed deletion uses the member-deletion dialog pattern, exact stored-name phrase/version rechecks and fresh server authority. The shared authority lock atomically marks the group deleted, removes current participant associations, revokes Lead assignments/sessions/access versions, invalidates pending credentials and records safe audits. Member/account records and historical relations/snapshots remain. Every ordinary/private/published read excludes the group, and cached landing/working/published paths are invalidated after commit. Cache uncertainty is reported; stale requests/redemption cannot restore the group. No restore or personal-erasure claim.

The protected **Published preview** renders the stored snapshot with the same escaped rich renderer. Working edits cannot alter this view until publication; no public renderer is introduced.
